선택한 로봇: Dreame L40 Ultra Gen 2

  • 제조사 페이지: dreametech.com · L40 Ultra Gen2
  • 구매 링크 (Amazon, ASIN B0FSJPFDPV): amazon.com/dp/B0FSJPFDPV
  • 로봇 35 × 35 × 9.7 cm · 도크 45.7 × 34 × 59 cm · 먼지봉투 3.2 L (최대 100일) · 배터리 5,200 mAh, 최대 231분 (조용 모드)

  • Matter는 "향후 OTA로 제공 예정"으로 표시돼 있습니다 (2026년 10월 기준).

  • 로봇 35 × 35 × 10.4 cm · 배터리 6,400 mAh · 최대 약 200분 · 12,000 Pa.
  • RGB 카메라 + 3D 구조광으로 약 120종 사물 인식 (Valetudo에서는 영상이 밖으로 나가지 않음).
  • 정가 $1,899였던 이전 세대 상급 모델이라 재고 할인 가격 편차가 큼.

방화벽 규칙 요지

  • WAN에서 들어오는 포트 없음. 외부 접속은 cloudflared가 밖으로 연 터널만.
  • Matter는 IPv6 링크 로컬과 mDNS를 쓰므로 VLAN 10↔20 사이 mDNS 반사(Avahi) 필요.
  • 카메라 펌웨어 업데이트는 관리자가 수동으로, 평소 인터넷 차단.
  • 미니 PC가 NTP 서버 역할, 카메라·로봇 시간 동기 (위치 융합에 필수).
  • 로봇 Wi-Fi는 2.4 GHz WPA2, 신호 세기 −65 dBm 이상을 본당 전체에서 확인.

7 · 태그 부착

로봇 윗면 뒤쪽에 10 cm AprilTag

부착 규칙

  • tag36h11, R1 = ID 0, R2 = ID 1, R3 = ID 2. 태그 위쪽 변이 로봇 진행 방향을 향하게.
  • LiDAR 돔, 범퍼, 버튼, 통풍구를 가리지 않는 뒤쪽 평평한 면. 위치는 실물을 받아 확정.
  • 무광 라미네이트 비닐 (천장 조명 반사 방지), 두께 < 0.3 mm. 로봇 높이 변화 무시 가능.
  • 흰 테두리(콰이어트 존) 1칸 폭을 꼭 남김. 테두리가 없으면 검출률이 크게 떨어짐.
  • 붙인 뒤 로봇을 바닥 기준 표시에 놓고 4방향 촬영으로 t_tag(중심 오프셋)와 각도 오프셋을 측정.
  • 월 1회 마른 천으로 닦기. 긁힘·들뜸이 보이면 예비 태그로 교체.

10 · 설치 · 보정

순서대로 하면 하루 반

1일차 오전: 네트워크·서버

  1. 방송실 랙에 UPS, 스위치, 미니 PC 설치. VLAN 10/20/30 구성
  2. AP 설치, 본당 전체 2.4 GHz 신호 측정 (휴대폰 앱, −65 dBm 이상)
  3. 미니 PC에 Ubuntu 24.04 + Docker, docker compose --profile site up -d
  4. Home Assistant에서 로봇 3대 Matter 연결, dreame_vacuum 로그인

1일차 오후: 로봇·도크

  1. 도크 배치, 회로 분리 확인, 물탱크 비움, 온수·건조 끔
  2. 로봇마다 앱에서 지도 작성 (의자 정위치 상태), 금지 구역 4곳·가상 벽 설정
  3. 흡입 전용 모드, 카페트 강흡입 켬, 펌웨어 업데이트 확인 (Matter OTA)
  4. AprilTag 부착, t_tag 측정

2일차 오전: 카메라·보정

  1. 체커보드로 카메라 내부 보정 (설치 전 책상에서 해 두면 빠름)
  2. 천장 설치, PoE 연결, NTP 확인
  3. 바닥에 ArUco 6장 → 줄자로 F 좌표 측정 → H_i 계산
  4. 로봇 지도 기준점 3–4개로 T_k 계산
  5. 검증: 바닥 표시 10곳에 로봇을 놓고 위치 오차 측정 (목표 95% < 5 cm)

2일차: 시험 운행

  1. R1 단독, 1열 앞 3줄만 → 의자 밑 통과 확인
  2. 3대 동시, 문 대기·재배분 확인
  3. 관리 페이지에서 긴급 정지·모두 복귀 시험
  4. 청소율 기준값 기록
